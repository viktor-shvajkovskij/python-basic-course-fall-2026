# Курс «Язык программирования Python» (осень 2026)

Добро пожаловать на курс по программированию на Python!

В ходе курса вы изучите:

* основы программирования на Python;
* ключевые библиотеки для вычислений и работы с данными;
* различные структуры данных и типы данных;
* основы алгоритмов анализа данных.

Обучение будет проходить в формате интерактивных практикумов. Материалы курса и задания доступны в этом репозитории.

Удачи в освоении новых знаний!
